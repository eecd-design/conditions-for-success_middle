If you are experiencing performance issues or visual glitches, we recommend first trying to "Repair Saved Data" from the "Data Management" section of this **Support** page.

If the issue persists, do the following:

1. Download backup copies of all assessments from "Manage Assessments" on **The Big Seven** page.
2. "Delete Saved Data" from the "Data Management" section of this **Support** page.
3. Import all downloaded files using the "Import Assessment" section of "Manage Assessments" on **The Big Seven** page.
4. "Open" the assessment you wish to resume.
